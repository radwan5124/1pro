# نظام حسابي بسيط باستخدام بايثون

هذا المشروع عبارة عن نظام حسابي بسيط (CLI) يسمح لك بـ:

- إضافة الإيرادات (Income)
- إضافة المصروفات (Expense)
- عرض كل الحركات
- عرض إجمالي الإيرادات والمصروفات والرصيد
- عرض الملخص حسب الفئة
- حفظ البيانات تلقائيًا داخل ملف JSON

## التشغيل

```bash
python3 accounting_system.py
```

## تشغيل الاختبارات

```bash
python3 -m unittest discover -s tests -v
```

## ملاحظات

- البيانات تُحفظ افتراضيًا في ملف `transactions.json` داخل نفس مجلد المشروع.
- يمكنك تعديل المسار داخل الكود عند إنشاء `AccountingSystem` إذا أردت.
